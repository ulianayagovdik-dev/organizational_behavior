# Тренажёр по организационному поведению

Карточки и пробный тест по лекциям 1–15 курса «Организационное поведение» (ВШБ НИУ ВШЭ).

- **Карточки** — 139 вопросов с ответами и номерами слайдов, интервальные повторения (1 → 3 → 7 → 14 → 30 дней).
- **Пробный тест** — 81 вопрос в формате экзамена: один ответ, несколько ответов, соответствие, вставить слово, открытые вопросы. Кнопка «Новый вариант» каждый раз собирает новый тест и перемешивает варианты ответов.

Прогресс хранится в браузере у каждого пользователя.

## Как выложить на GitHub Pages

1. Создай репозиторий на github.com (например, `op-trainer`), сделай его **Public**.
2. Нажми **Add file → Upload files** и загрузи `index.html` (и этот README).
3. Открой **Settings → Pages**, в разделе *Build and deployment* выбери **Deploy from a branch**, ветка `main`, папка `/ (root)` → **Save**.
4. Через 1–2 минуты сайт будет доступен по адресу `https://<твой-логин>.github.io/op-trainer/`.
   Ссылку на сразу открытый тест можно давать так: `https://<твой-логин>.github.io/op-trainer/#test`

## Как добавить вопросы

Открой `index.html` и найди массив `const Q=[` (вопросы теста) или `const C = [` (карточки). Форматы:

```js
{t:"single", l:"7", p:1, q:"Вопрос", opts:["A","B","C"], ans:[1]}          // один ответ (номера с нуля)
{t:"multi",  l:"7", p:1, q:"Вопрос", opts:["A","B","C"], ans:[0,2]}        // несколько ответов
{t:"match",  l:"7", p:2, q:"Вопрос", left:["X","Y"], right:["1","2"], map:[[1],[0]]}
{t:"fill",   l:"7", p:1, q:"Вопрос ____", acc:["начало слова"], show:"слово"}
{t:"open",   l:"7", p:3, q:"Вопрос", model:"Эталонный ответ", keys:["пункт 1","пункт 2"]}
```

`l` — номер лекции: 1, 2, 3 (3–4), 5 (5–6), 7 (7–8), 9 (9–10), 11, 12, 13, 14, 15. `src:1` помечает пример, показанный на лекции.
