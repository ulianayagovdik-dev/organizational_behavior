# Тренажёр по организационному поведению

Карточки и пробный тест по лекциям 1–15 курса «Организационное поведение» (ВШБ НИУ ВШЭ).

- **Карточки** — 139 вопросов с ответами и номерами слайдов, интервальные повторения (1 → 3 → 7 → 14 → 30 дней).
- **Пробный тест** — 81 вопрос в формате экзамена: один ответ, несколько ответов, соответствие, вставить слово, открытые вопросы. Кнопка «Новый вариант» каждый раз собирает новый тест и перемешивает варианты ответов.

Прогресс хранится в браузере у каждого пользователя.
